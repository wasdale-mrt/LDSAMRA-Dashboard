About these figures

  • Read each night from the LDSAMRA call-out log.
  • "Last year" means the same months last year, so the numbers are fair to compare.
  • Team hours come in monthly, so the latest month can be missing for a while.
  • Injury, medical, age band and sex count casualties, so they can add up to more than the number of call-outs.
  • No names, exact dates or casualty details are shown.
