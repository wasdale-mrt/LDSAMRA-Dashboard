# LDSAMRA Dashboard

Call-out statistics and map for the Lake District Search & Mountain Rescue
Association, updated each night from the LDSAMRA call-out log.

Website: https://wasdale-mrt.github.io/LDSAMRA-Dashboard/

This repository holds the page and the script that builds it. It holds no
call-out data: the figures are worked out fresh each night and published
straight to the website.
